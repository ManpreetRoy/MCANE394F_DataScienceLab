# Lab 01 – Basic Data Science

## Course Information

- **Program:** Master of Computer Applications (MCA)
- **Course:** Data Science Lab
- **Course Code:** MCANE394F
- **Assignment:** MCA Assignment / Basic Data Science / 01
- **Language:** Python

## Objective

To implement basic Python programming, data structures,
recursion, NumPy matrix operations, and mathematical concepts
used in Data Science.

## Tools Used

- Google Colab
- Python
- NumPy

## Assignment Questions

### Python Programming

1. Intersection, Union and Symmetric Difference without set operations
2. Remove duplicate elements while preserving original order
3. Generate all possible subsets using recursion
4. Find the most frequent word in a text file
5. Convert and validate a Roman numeral

### NumPy and Matrix Operations

6. Create and analyze matrices using NumPy
7. Perform matrix addition, subtraction and element-wise multiplication
8. Calculate determinant and inverse of a matrix
9. Solve a system of linear equations using matrix method
10. Check whether a matrix is symmetric or skew-symmetric

## Learning Outcomes

After completing this lab, the student will be able to:

- Work with Python lists and collections
- Implement algorithms without relying on built-in set operations
- Understand recursion
- Process text data
- Work with NumPy matrices

- Solve basic linear algebra problems using Python
